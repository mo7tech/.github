## 🌐 关于我们 / About Us

## 🎯 研发与探索方向 / Focus Areas

我们目前正专注于以下领域的研发与产品孵化：

- 🎮 **独立游戏开发 (Indie Game Dev)**：基于 C# 及相关引擎生态，探索独特的玩法机制、交互体验与小而美独立游戏项目。
- ⚙️ **高性能服务端与工具链**：基于 .NET 与 Go 构建高可靠后台服务、CLI 工具及自动化脚本。
- 🖥️ **现代 Web 与数字化应用**：结合 TypeScript 生态与现代化前端技术，构建高效、体验优秀的数字化产品。
